# معماری فنی پیشنهادی همراه‌یار

## ساختار
Flutter / Dart با جداسازی لایه‌ها:
- `app/`: راه‌اندازی، پوسته، مسیرها و dependency injection
- `core/`: localization، theme، error handling، date/time، storage، security
- `features/<module>/presentation`: صفحات و ویجت‌ها
- `features/<module>/domain`: مدل‌ها و قواعد کسب‌وکار
- `features/<module>/data`: repository، منابع محلی و remote
- `integrations/`: پرداخت، نقشه، مکان‌ها و رزرو؛ هرکدام پشت interface مستقل

## قراردادهای مهم
- ذخیره تاریخ رویدادها به‌صورت تاریخ/زمان استاندارد به‌همراه timezone؛ تاریخ روزِ بدون زمان به‌صورت civil date ذخیره شود تا جابه‌جایی timezone تاریخ را عوض نکند.
- تبدیل Jalali/Gregorian از یک کتابخانه تست‌شده و محدودیت بازه پشتیبانی‌شده صریح باشد. تاریخ‌های خارج از بازه نباید بی‌صدا تبدیل شوند.
- زبان و منطقه زمانی از کشور مستقل باشند؛ کاربر بتواند زبان فارسی را با منطقه زمانی اروپا یا برعکس استفاده کند.
- داده‌های آفلاین در repository محلی نگهداری و با سرویس همگام‌سازی اختیاری توسعه داده شوند.
- دسترسی به موقعیت مکانی، اعلان‌ها، فایل‌ها و سلامت فقط در زمان نیاز و با توضیح روشن درخواست شود.
- کلیدهای API و اسرار در کد کلاینت یا مخزن قرار نگیرند.
- پرداخت و رزرو از طریق adapterهای کشورمحور و فقط ارائه‌دهندگان مجاز؛ در نبود provider، فقط یادآور/لینک رسمی ارائه شود.
- نقشه آفلاین به‌صورت بسته‌های منطقه‌ای با نمایش حجم، checksum، مدیریت فضای ذخیره‌سازی و امکان حذف باشد.
- داده‌های سلامت و اسناد در سطح دیتابیس/فایل با رمزگذاری و قفل برنامه محافظت شوند؛ گزارش‌گیری و analytics نباید محتوای حساس را ثبت کند.

## کیفیت
- unit test برای تاریخ، سن، محاسبات مالی و قواعد تکرار یادآور
- widget test برای RTL/LTR و صفحات اصلی
- integration test برای ذخیره‌سازی، اعلان و بازیابی backup
- CI: format، analyze، test و ساخت APK release
- dependencyها قبل از افزودن از نظر نگهداری، مجوز، اندازه و پشتیبانی Android/iOS ارزیابی شوند

## نقشه/تقویم
- بسته‌های تقویم باید تبدیل تاریخ و محدوده سال را مستند کنند؛ ویجت تقویم به‌تنهایی جای موتور تاریخ و تست را نمی‌گیرد.
- موتور نقشه باید مجوز استفاده از داده‌ها، امکان دانلود و مسیریابی آفلاین، حجم نقشه، پوشش کشورها و پشتیبانی iOS/Android را بررسی کند.
