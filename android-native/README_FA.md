# همراه‌یار – نسخه آزمایشی بومی اندروید 0.4.0

## امکانات قابل استفاده
- رابط چهارزبانه فارسی، انگلیسی، عربی و آلمانی با جهت نوشتار مناسب.
- نمایش تاریخ روز و تبدیل تاریخ میلادی به شمسی.
- محاسبه BMI با توضیح اینکه ابزار تشخیصی پزشکی نیست.
- محاسبه سن بر اساس تاریخ تولد میلادی.
- دفتر هزینه شخصی با جمع مبالغ ثبت‌شده.
- ثبت یادآور با انتخاب تاریخ و ساعت و ارسال اعلان محلی؛ نیازمند اجازه اعلان در تنظیمات گوشی است.
- فهرست تکالیف، مدارک، سوابق نگهداری خانه و خودرو، یادداشت سفر و مکان‌های ذخیره‌شده.
- اطلاعات ماژول‌های محلی روی همان دستگاه ذخیره می‌شوند؛ برای حذف هر مورد آن را لمس طولانی کنید.

## محدودیت‌های مهم
همگام‌سازی ابری و حساب کاربری هنوز وجود ندارد. بخش مالی دفتر ثبت شخصی است و پرداخت بانکی یا قبض انجام نمی‌دهد. نقشه آفلاین، مکان‌یابی زنده، رزرو هتل و داده زنده بیمارستان/داروخانه و خدمات پزشکی به API و مجوز ارائه‌دهندگان معتبر نیاز دارند و هنوز فعال نیستند. یادآورهای محلی ممکن است پس از راه‌اندازی مجدد گوشی نیاز به ثبت مجدد داشته باشند.

## ساخت و انتشار
پوشه `android-native` را در Android Studio باز کنید یا از GitHub Actions خروجی APK بگیرید. APK آزمایشی Debug با کلید توسعه امضا شده و برای نصب و تست گوشی مناسب است. APK نسخه Release فعلی unsigned است و برای انتشار فروشگاهی باید با کلید خصوصی خود مالک امضا شود؛ کلید را در مخزن عمومی قرار ندهید.
