# همراه‌یار – پایه بومی اندروید

امکانات اجرایی این نسخه: داشبورد RTL، نمایش تاریخ امروز شمسی/میلادی، تبدیل محاسباتی میلادی به شمسی، محاسبه BMI، ثبت و حذف یادآور محلی.

پرداخت قبض، اعلان زمان‌بندی‌شده، مناسبت‌های چندکشوری، نقشه آفلاین، رزرو هتل و اطلاعات مراکز درمانی هنوز پیاده‌سازی یا به ارائه‌دهنده معتبر متصل نشده‌اند.

برای ساخت، پوشه `android-native` را در Android Studio باز کنید. CI نیز APK آزمایشی را می‌سازد.
