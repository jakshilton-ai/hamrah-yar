# همراه‌یار | Hamrah-Yar

**سوپر اپلیکیشن جامع زندگی برای ایران و کشورهای دیگر**

همراه‌یار با معماری ماژولار و پشتیبانی چندزبانه توسعه می‌یابد.

## زبان‌ها
- فارسی (RTL)
- English (LTR)
- العربية (RTL)
- Deutsch (LTR)

تغییر زبان از داخل برنامه انجام می‌شود و انتخاب کاربر روی دستگاه ذخیره می‌ماند.

## نقشه امکانات
- داشبورد و تقویم، تبدیل تاریخ، مناسبت‌ها و یادآورها
- مالی، بودجه، اقساط و پرداخت قبض از طریق ارائه‌دهنده مجاز
- سلامت، تغذیه، فعالیت و محتوای سلامت روان با رویکرد ایمن و غیرتشخیصی
- آموزش، درس و برنامه‌ریزی
- اسناد، خانه و خودرو
- نقشه آنلاین و بسته‌های آفلاین، طبیعت‌گردی و سفر
- هتل، بیمارستان، داروخانه و خدمات شهری با اطلاعات به‌روز و منبع‌دار
- گزارش، خروجی و پشتیبان‌گیری

## وضعیت نسخه بومی اندروید
در پوشه `android-native/` نسخه بومی آزمایشی 0.4.0 قرار دارد: داشبورد چهارزبانه، تاریخ امروز، تبدیل میلادی به شمسی، BMI، دفتر هزینه و جمع مبالغ، محاسبه سن، یادآورهای ذخیره‌شده، فهرست تکالیف، مدارک، نگهداری خانه/خودرو، یادداشت سفر و فهرست مکان‌های ذخیره‌شده. داده‌های این ماژول‌ها محلی و روی همان دستگاه هستند. پرداخت واقعی، اعلان زمان‌بندی‌شده، نقشه و رزرو آنلاین و فهرست زنده مراکز هنوز به سرویس‌های بیرونی و مجوزهای رسمی نیاز دارند.

## حفاظت از مالکیت نرم‌افزار
هیچ اپلیکیشن سمت کاربر را نمی‌توان صددرصد غیرقابل کپی کرد. برای سخت‌تر کردن مهندسی معکوس و محافظت از خدمات اختصاصی باید نسخه انتشار با R8/ProGuard مبهم‌سازی شود، کلید امضای انتشار محرمانه بماند، منطق حساس و کلیدهای API در سرور نگهداری شوند، API با احراز هویت و کنترل سوءاستفاده محافظت شود و در صورت نیاز از Play Integrity یا راهکارهای معتبر پلتفرم استفاده شود. این اقدامات بازدارنده‌اند، نه تضمین مطلق.
